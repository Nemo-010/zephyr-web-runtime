128×64 monochrome OLED

LVGL, compiled to WebAssembly, rendering into a 1bpp panel buffer. The image is drawn from the panel's own bytes: eight vertical pixels per byte, bit 7 first, exactly as an SSD1306 receives them.

Controls

The two buttons are the gpio-keys this project's board really has, and the numbers are their zephyr,code values read from its devicetree. Press them, or use the keyboard:

Honest notes

  • This is LVGL, not the Zephyr kernel. Zephyr's kernel cannot currently be built for WebAssembly, because its heap-size constants are emitted as absolute symbols, which wasm has no representation for.
  • What is faithful is the part that matters for judging a UI: the same widget tree, the same 1bpp packing, the same bit order, and the same panel geometry.
